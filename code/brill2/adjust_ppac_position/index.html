    PPAC 位置矫正算法

    概述

    adjust_ppac_position 程序通过最小化 PPAC 径迹拟合残差，自动确定 PPAC2 和 PPAC3 相对于 PPAC1 的位置偏移量。该程序采用四阶段精化算法，并引入正则化项解决 3点PPAC 系统的固有数学简并性。

    物理背景

    PPAC 探测器系统由三个 PPAC 组成（PPAC1、PPAC2、PPAC3），粒子依次穿过它们。理想情况下，三点应在一条直线上。但由于机械安装误差，PPAC2 和 PPAC3 的位置可能存在偏移量 (dx2, dx3) 和 (dy2, dy3)。

    对每个有效事件（x_used_ppac == 7 或 y_used_ppac == 7），有三个测量点 (z_i, pos_i) 需要拟合一条直线 pos = a + b*z。拟合残差为：

    \[R_i(d_2, d_3) = \min_{a,b} \sum_{k=1}^3 \left(pos_k + d_k - (a + b \cdot z_k)\right)^2\]

    其中 \(d_1 = 0\)（PPAC1 作为参考点），\(d_2, d_3\) 为 PPAC2 和 PPAC3 的位置偏移。

    算法流程

    Stage 1: 粗网格搜索 (0.5 mm 步长)

    在搜索范围 [-n, +n] mm 内以 0.5 mm 步长进行二维网格扫描，找到使平均残差最小的 (d2, d3)。

    Stage 2: 细网格搜索 (0.1 mm 步长)

    以 Stage 1 结果为中心，在 ±0.5 mm 范围内以 0.1 mm 步长进行精化搜索。

    Stage 3: 抛物线插值（亚网格精度）

    在细网格最优解附近取 9 个点，拟合二次曲面：

    \[R(d_2, d_3) = A d_2^2 + B d_3^2 + C d_2 d_3 + D d_2 + E d_3 + F\]

    解析求解二次曲面的极小值点，获得亚网格精度（< 0.1 mm）的最优解。

    Stage 4: 不确定性估计

    以 0.5 mm 步长在最优解附近重新计算 Hessian 矩阵，通过以下公式估计参数的不确定性：

    \[\sigma_{d_2} = \sqrt{\frac{R_{\text{best}}}{N} \cdot \frac{2B}{\det H}}, \quad \sigma_{d_3} = \sqrt{\frac{R_{\text{best}}}{N} \cdot \frac{2A}{\det H}}\]

    其中 \(H = \begin{bmatrix} 2A & C \\ C & 2B \end{bmatrix}\) 为 Hessian 矩阵，\(\det H = 4AB - C^2\)。

    3点PPAC 系统的简并性问题

    数学根源

    用 3 个点拟合一条直线（2 个参数：截距和斜率），系统的自由度为 1。PPAC2 和 PPAC3 的偏移不是独立确定的：存在一个简并方向，沿着该方向移动 (d2, d3) 不会改变拟合残差。

    对于理想情况（\(z_1 = -L, z_2 = 0, z_3 = L\)），Hessian 矩阵为：

    \[H = \begin{bmatrix} 4/3 & -2/3 \\ -2/3 & 1/3 \end{bmatrix}\]

    其行列式 \(\det H = 0\)，零空间为 \([1, 2]^T\)。这意味着：

    \[R(d_2 + t, d_3 + 2t) = R(d_2, d_3) \quad \forall t\]

    残差曲面是一个平坦的"谷底"，而非一个孤立的极小值点。

    为什么普通网格算法失效

    普通网格算法（无正则化）只在谷底找到一个任意点，该点的具体位置取决于：

    1. 统计涨落：不同 run 的事例统计不同，谷底的微小扰动会导致最优解在谷底滑动
    2. 网格离散化：有限步长的网格搜索会在谷底任意位置停止
    3. 初始条件敏感：搜索起点和步长的微小变化导致完全不同的结果

    实验验证：以 run 60 和 run 57 的 Y 方向为例：

    算法 run 60 run 57 差异
    无正则化 dy2=3.1, dy3=4.9 dy2=-1.4, dy3=-4.0 ~4.5 mm
    有正则化 dy2=0.49, dy3=-0.25 dy2=0.49, dy3=-0.24 ~0.01 mm

    无正则化结果的差值 (4.5, 8.9) ≈ 4.5 × (1, 2)，恰好沿着简并方向，验证了上述分析。

    正则化方案

    在残差函数中加入一个小的惩罚项，偏好接近原点的解：

    \[R_{\text{reg}}(d_2, d_3) = R(d_2, d_3) + \lambda \cdot (d_2^2 + d_3^2)\]

    其中 \(\lambda = R_{\text{baseline}} / (100 \cdot n^2)\)。该惩罚项在搜索范围边缘（±n mm）处贡献约 1% 的基线残差，足够打破简并性，同时不会显著偏置良好确定的组合。

    正则化等效于：在平坦的谷底中，选择距离原点（即假设 PPAC 近似对齐）最近的解。这是最符合物理直觉的选择。

    结果解读

    1. Y 方向：偏移量约 0.5 mm，残差改善 ~59%，说明 Y 方向存在显著的、物理上真实的 PPAC 位置偏移。各 run 结果高度一致（标准差 < 0.01 mm）。

    2. X 方向：偏移量约 0.15 mm，残差改善仅 ~4%，说明 X 方向偏移很小，残差曲面近乎平坦。X 方向的结果更多依赖于正则化而非数据本身，不确定性较大。

    3. 跨 run 一致性：正则化后各 run 结果高度一致，验证了算法的有效性。

    程序用法

    ./build/bin/adjust_ppac_position -r <run> [-t <trigger>] [-n <half_size>]
    选项 说明 默认值
    -r, --run Run 号 必填
    -t, --trigger 触发类型：main 或 t1 main
    -n 搜索范围半宽 (mm) 5

    输出文件保存至 /data/disk1/ribll2026_www_data/track/ppac_offset_<trigger>_<run>.txt。

    参考文献

    该算法基于以下物理原理： - 最小二乘直线拟合的残差最小化 - Tikhonov 正则化（L2 正则化）处理不适定问题 - 有限差分法估计 Hessian 矩阵和参数不确定性
